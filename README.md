# My First VS Code Project

A simple HTML/JavaScript project to get started with web development.

## Project Structure

- `index.html` - Main HTML file
- `style.css` - CSS styling
- `script.js` - JavaScript functionality

## How to Use

1. Open `index.html` in your web browser
2. Or use a live server extension in VS Code for auto-refresh

## Getting Started

- Edit the HTML in `index.html`
- Add your styles in `style.css`
- Write your JavaScript code in `script.js`

Enjoy coding!
